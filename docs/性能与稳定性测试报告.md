# GreenLoop 性能与稳定性测试报告

## 环境与口径

- 目标：Docker 本地 API（`http://localhost:8080`）与独立压测数据。
- 工具：k6；读接口阈值 P95 < 500ms、P99 < 1s，金融写接口 P95 < 1s、P99 < 2s。
- 金融压测结束后，必须执行 `campus-trade-api/src/test/resources/finance-reconciliation.sql`；守恒差额应为 0，异常查询返回 0 行。

## 脚本

- `scripts/performance/product-list.js`：热门商品列表读压测。
- `scripts/performance/core-flow.js`：注册/登录后执行充值、发布、下单、支付冻结、确认收货的混合流程。
